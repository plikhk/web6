## Description
A five-page site that demonstrates jQuery (loaded from the code.jquery.com CDN). The navbar at the top of every page links to each part of the assignment.

| Page | Tasks |
| --- | --- |
| `index.html` | Task 0 setup (`$(document).ready`, console message), Task 1 selectors and `.text()`, `.html()`, `.css()` |
| `effects.html` | Task 2 hide/show/toggle, Task 3 fade, Task 4 slide |
| `dom.html` | Task 5 append/prepend/remove, Task 6 `.attr()` for image src and link href, Task 7 live form output with `.val()` and `.text()` |
| `animations.html` | Task 8 basic `.animate()`, Task 9 sequential animation, Task 10 combined animation |
| `project.html` | Task 11 mini project: Accordion Menu with slide animations |

## How to run
1. Clone or download the repository.
2. Open `index.html` in a browser (an internet connection is needed for the jQuery CDN and the sample images).
3. Open the console (F12) to see `jQuery is ready!`.
